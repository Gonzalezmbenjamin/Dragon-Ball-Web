# 🐉 Dragon Ball — Proyecto Web

Sitio web **fan-made y académico** inspirado en el universo de **Dragon Ball**, desarrollado como proyecto de programación web.

El sitio reúne información sobre sus principales sagas, personajes, transformaciones y películas dentro de una experiencia visual responsive inspirada en la estética de la franquicia.

---

## ✨ Características

- Diseño **responsive** para desktop, tablet y dispositivos móviles.
- Navegación entre las distintas secciones del sitio.
- Cronología de las principales sagas de **Dragon Ball, Dragon Ball Z y Dragon Ball Super**.
- Sección de personajes y antagonistas.
- Selector interactivo de transformaciones.
- Catálogo de películas.
- Galería visual.
- Animaciones y microinteracciones realizadas con CSS y JavaScript.
- Formulario de contacto con validaciones del lado del cliente.
- Proyecto completamente estático y compatible con **GitHub Pages**.

---

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| **HTML5** | Estructura y contenido |
| **CSS3** | Diseño, responsive y animaciones |

## 📂 Secciones

### 🏠 Inicio

Presentación principal del sitio y acceso a las distintas áreas del proyecto.

### ⏳ Sagas

Recorrido por las principales etapas de:

**Dragon Ball → Dragon Ball Z → Dragon Ball Super**

Cada saga incluye información, imágenes y referencias a sus acontecimientos principales.

Galería de héroes, Guerreros Z y antagonistas destacados de la franquicia.

### ⚡ Transformaciones

Sección interactiva dedicada a algunas de las transformaciones más importantes de los personajes.

### 🎬 Películas

Recorrido por las películas animadas de Dragon Ball, Dragon Ball Z y Dragon Ball Super.

### 🖼️ Galería

Selección de imágenes y momentos representativos del universo Dragon Ball.

### ✉️ Contacto

Formulario demostrativo con validación mediante JavaScript.

## 📩 Formulario de contacto

El formulario incluido en el proyecto es **demostrativo**.

Actualmente:

- valida los campos en el navegador;
- verifica los datos ingresados;
- muestra feedback visual al usuario;
- simula el envío correctamente;
- limpia los campos después de completar la acción.

**No envía ni almacena información en ningún servidor o base de datos.**

Esta decisión permite mantener la versión publicada en GitHub Pages completamente estática.

---

## 🚀 Publicación en GitHub Pages

Para publicar el proyecto:

1. Subir el contenido del proyecto a la raíz de un repositorio de GitHub.
2. Abrir el repositorio.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir:

   - Branch: `main`
   - Folder: `/ (root)`

6. Guardar los cambios.

GitHub generará automáticamente la URL pública del proyecto.

Ejemplo:

```text
https://usuario.github.io/gonzalezmbenjamin/
```

## 🔗 Rutas

Todas las rutas internas fueron desarrolladas utilizando **rutas relativas**.

Esto permite que el proyecto funcione correctamente al ser publicado dentro de un subdirectorio de GitHub Pages, sin depender de rutas absolutas o de un servidor backend.

## 📱 Responsive Design

El sitio fue diseñado para adaptarse a diferentes tamaños de pantalla:

- Desktop
- Notebook
- Tablet
- Smartphone

Se utilizaron **CSS Grid, Flexbox y media queries** para reorganizar los distintos componentes según el dispositivo.
