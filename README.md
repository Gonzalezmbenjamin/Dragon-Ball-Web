# Dragon Ball — Proyecto web

Sitio fan-made y académico inspirado en Dragon Ball, desarrollado como proyecto de programación web.

## Tecnologías

- HTML5
- CSS3
- JavaScript vanilla
- Font Awesome
- Google Fonts

La versión pública está preparada para **GitHub Pages** y funciona de forma completamente estática.

## Secciones

- Inicio
- Sagas
- Personajes y Transformaciones
- Películas
- Galería
- Contacto

## Contacto

El formulario de contacto es **demostrativo**: valida los campos en el navegador, muestra feedback visual y limpia el formulario, pero no envía ni almacena información.

## Publicación en GitHub Pages

1. Subí el contenido del proyecto a la raíz de un repositorio de GitHub.
2. En el repositorio, abrí **Settings → Pages**.
3. En **Build and deployment**, seleccioná **Deploy from a branch**.
4. Elegí la rama `main` y la carpeta `/ (root)`.
5. Guardá los cambios y esperá a que GitHub publique la URL.

Todas las rutas del sitio son relativas, por lo que el proyecto funciona correctamente bajo una URL del tipo:

`https://usuario.github.io/nombre-del-repositorio/`
